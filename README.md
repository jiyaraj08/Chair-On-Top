# Chair on Top

Interior-design discovery and budget-planning website (college project).

Built with FastAPI, Jinja2, HTML, CSS, vanilla JavaScript, Supabase, GitHub and Render.

## Run locally (Windows CMD)

    python -m venv venv
    venv\Scripts\activate
    python -m pip install -r requirements.txt
    python -m uvicorn main:app --reload

Then open http://127.0.0.1:8000 in your browser.
